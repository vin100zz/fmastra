# À faire

Les chantiers proposés mais pas encore codés : leur document de conception, avec ses
décisions ouvertes, et ce qui a servi à l'écrire (maquettes). `docs/` décrit le jeu tel
qu'il est ; rien ici ne l'est encore.

Quand un chantier est codé, son document passe dans `docs/`, avec une section « Ce
qui a changé à l'implémentation » et les chiffres mesurés, dans le même changement que
le code, et quitte ce dossier.
